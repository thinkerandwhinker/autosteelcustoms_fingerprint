# Autosteel Customs Fingerprint

Repositori ini menampung kode dan ketentuan dalam pengembangan dan implementasi firmware untuk board dengan chip `ESP WROOM 32-U`. Dikembangkan dengan framework `ESP IDF`. Templat ini diperoleh dari repository [Espressif esp-idf-template](https://github.com/espressif/esp-idf-template) dan telah dimodifikasi pada beberapa bagian untuk menyesuaikan dengan kebutuhan dari firmware yang akan dikembangkan.
